Privacy Policy / Chính sách bảo mật

Effective date / Ngày hiệu lực: 15/10/2026

1. Who we are

"Ho So Pha An" is a private desktop application operated by the owner of the YouTube channel "Hồ Sơ Phá Án" (@kenhhosophaan). It runs only on the owner's own computer and is used only to manage the owner's own YouTube channel. It is not offered to the public.

2. How the application uses YouTube API Services

The application uses YouTube API Services to:

  • upload videos and set their title, description, thumbnail, scheduled publish time and AI-content disclosure on the owner's channel;
  • read basic statistics (views, watch time, subscribers) of the owner's own channel to produce a private weekly report.

By using this application you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data accessed, stored and shared

  • The only Google account accessed is the channel owner's own account, after the owner grants permission through Google's sign-in screen.
  • The OAuth access/refresh token and channel statistics are stored only on the owner's computer. They are not sent to any server operated by us and are not stored in any cloud database.
  • No data is sold, shared with, or disclosed to any third party.
  • No data from any other YouTube user is collected.
  • The application does not use cookies or tracking on this website.

4. Retention and deletion

Stored statistics are kept only as long as needed for the weekly report and can be deleted at any time by the owner. Access can be revoked at any time at Google security settings – Third-party apps with account access; after revocation the stored token is deleted from the computer.
